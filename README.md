# Neon Bastion

Tower defense néon à niveaux infinis, installable sur iPhone et Android (application web progressive).

## Installer
- **iPhone** : ouvrir l'adresse du jeu dans Safari, Partager, « Sur l'écran d'accueil ».
- **Android** : ouvrir l'adresse dans Chrome, menu ⋮, « Installer l'application ».

## Mises à jour
L'application télécharge la dernière version à chaque ouverture et reste jouable hors ligne. Si une mise à jour arrive pendant une partie, un bandeau propose de l'appliquer.

## Contenu
- `source/neon-bastion.html` : le jeu (fichier unique).
- `tools/build.py` et `tools/icons.py` : construisent l’application (page, manifeste, service worker, icônes).
- `.github/workflows/pages.yml` : à chaque modification, GitHub reconstruit et republie l’application.
